# DotDot

手帐风的习惯打卡。每个习惯一张卡片、一张 GitHub 式的点点图，帮你慢慢养成好习惯和日常 routine。

在线使用：https://ssbabysong.github.io/dotdot/

## 功能

- **今天**：按早晨 / 白天 / 晚上 / 随时分组的 routine，点一下就打卡；每行右边是最近 7 天的点点
- **每个习惯独立追踪**：自己的点点图、当前连续、最长连续、近 30 天完成率、累计次数
- **按星期安排**：每天、工作日、周末或自定义；休息日不会打断连续记录
- **补打卡**：在习惯详情的月历里点日期
- **routine 套装**：一键添加晨间 / 晚间 / 照顾身体三套起步习惯
- **备份**：导出 / 导入 JSON
- 可以“添加到主屏幕”当 App 用，离线也能打开；跟随系统浅色 / 深色模式

## 数据

所有记录保存在浏览器的 localStorage 里，不会上传到任何服务器。换设备或清理浏览器数据前，请先在「习惯」页导出备份。

## 开发

纯静态页面，没有构建步骤：`index.html`、`style.css`、`app.js`。本地直接打开 `index.html`，或运行 `python3 -m http.server` 后访问 http://localhost:8000。

修改后请把 `sw.js` 里的 `VERSION` 加一，这样已安装的用户会拿到新版本。
